# Watson 0.9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계서 7(0.9 사용자 점검 9항목)을 화면 쪽만 바꿔 반영한다.

**Architecture:** React 화면·lib 함수만 바꾼다. exe(SHELL 5)와 DB 스키마 버전은 그대로 둔다. 새 값은 기존 레코드의 선택 필드와 설정으로만 더한다.

**Tech Stack:** React 18, TS, Vite, Dexie, Vitest(jsdom), Playwright 캡처.

**Spec:** docs/superpowers/specs/2026-11-11-watson-feedback-0-9.md

## Global Constraints
- exe 무변경. 업데이트 매니페스트는 shell 1.
- 캡처에는 가상 학생 자료만 쓴다. 학생 이름은 AI로 보내기 전에 가린다.
- 문구는 쉬운 우리말로 쓴다.
- 판 번호는 0.9.0.

## Review Focus
- 한글 입력 중(isComposing)일 때 방향키·Enter가 줄을 옮기거나 저장하면 안 된다.
- 옛 layoutPrefs(place 없음)를 읽으면 모든 칸이 오른쪽에 있어야 한다.
- 폴더를 지우면 안의 노트가 사라지지 않고 위 폴더로 가야 한다. 사라진 folder_id를 가진 노트는 맨 위 목록에 나와야 한다.
- 구글 자동 맞춤은 로그인 안 한 상태·HTML판에서 아무 일도 하지 않아야 하고, 맞춤이 겹쳐 돌면 안 된다.
- 전달사항에서 빈 새 줄은 저장되지 않고, 떠나면 사라져야 한다.

### Task 4: 홈 배치
- `layoutPrefs`: PrefItem에 `place?: 'side' | 'tab'`. `panelH: Partial<Record<PanelKey, number>>`. `setPlace(list, key, place)`.
- 테스트: 옛 값을 읽으면 place는 side, panelH는 {}.
- `HomePage`:
  - 탭: 대화, 전달사항(늘 보임), place 'tab'인 칸.
  - 오른쪽: place 'side'인 칸. 칸을 `PanelFrame`(머리 단추 '왼쪽 탭으로' / 탭 안 '오른쪽으로', 높이 끌기, 두 번 누르면 맞춤)으로 감싼다.
  - sideW 한도는 240 ~ 본문 너비 × 0.6. 오른쪽 칸이 없으면 열을 없앤다.
- `LayoutSettings`: 칸마다 자리 고르기(오른쪽 / 왼쪽 탭 / 숨김).
- HomePage.test를 고친다: 전달사항 탭이 늘 보이는지, place tab인 칸이 탭으로 나오는지.

### Task 5: 전달사항 줄 편집
- `NoticeTab`: 아래 추가 폼을 없앤다.
  - '+ 추가'를 누르면 draft 줄이 생긴다(저장 안 됨). 글이 생긴 뒤 Enter나 blur에 addNotice.
  - Enter: 저장하고 다음 줄에 초점. 마지막 줄이면 draft를 만든다.
  - ↑↓←→ 줄 이동은 공통 `caretNav(e, el)` → 'up' | 'down' | null(src/lib/ui/caretNav.ts)로 판단한다.
  - row-tools는 오른쪽 끝(margin-left:auto).
- 테스트: NoticeTab.test에서 Enter 다음 줄, draft 비우면 사라짐, ↓ 이동.

### Task 6: 노트 편집기
- `caretNav` 공용.
  - ↑: 첫 줄이면(앞에 \n 없음) 위로.
  - ↓: 마지막 줄이면 아래로.
  - ←: 0이면 위 블록 끝으로. →: 끝이면 아래 블록 앞으로.
  - isComposing이면 null.
- 글 블록만 오가고, 열린 슬래시 메뉴가 먼저 받는다.
- `NOTE_SHORTCUTS`를 Ctrl+Shift와 Ctrl+Alt 모두 받는다. `noteShortcut(e): NoteBlockType | null` (blocks.ts). 테스트.
- `markdownPrefix(text): { type, rest } | null` — '# ', '## ', '- ', '* ', '1. ', '[] '. 스페이스를 쳐서 앞부분이 맞으면 바꾼다. 테스트.
- 정렬:
  - .nb의 앞에 고정 22px 표시칸(nb-mark / 체크 / 빈칸)을 둔다. 문단도 같은 빈칸을 가져 글 시작이 같다.
  - 캡처로 확인한다.
- SHORTCUT_TABLE에 노트 단축키를 싣는다. 슬래시 항목에 hint 단축키를 표시한다.
