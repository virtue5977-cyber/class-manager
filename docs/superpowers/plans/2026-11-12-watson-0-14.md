# Watson 0.14 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 설계서 12(0.14, 23항목 중 16번을 뺀 것과 전달사항 끌기)를 반영한다.
**Architecture:** 화면과 lib만 바꾼다. exe와 DB 스키마 버전은 그대로 두고, 새 값은 선택 필드로만 더한다.
**Tech Stack:** React 18, TS, Vite, Dexie, Vitest(jsdom), Playwright 캡처.
**Spec:** docs/superpowers/specs/2026-11-12-watson-0-14.md

## Global Constraints
- exe 무변경, 업데이트 shell 1, 판 0.14.0.
- 캡처는 가상 학생만. AI로 보내는 이름은 늘 가린다.
- 쉬운 우리말 문구.

## Review Focus
- 한글 조합 중(isComposing)에 자동완성·Enter·Esc가 끼어들지 않는다.
- 끌기를 위로·아래로, 맨 위·맨 아래로 해도 순서가 맞다(손잡이 없는 줄, 완료 줄 섞임 포함).
- 결석 기간 넣기: 주말·휴업일 제외, 이미 있는 날 덮어쓰기 묻기, 끝일 < 시작일 막기.
- 받은 일정(학사·NEIS·구글)은 상세에서 고치거나 지울 수 없다.
- 예전 기록(kind·place 없음, '교사' 대상)은 그대로 열린다.

### Task 1: 명령창
- suggest/CommandBar: 자동완성 줄에 앞 기호(`/`, `!`)를 다시 그리지 않는다. `!명령 ` 뒤 `@` → 학생·노트 후보(`/`와 같은 함수).
- skills: `!상담` = `!상담정리`. 자동완성에는 `!상담`. ai.ts 경로도 같이.
- 안내 문구: `/빠른 실행 · !AI 실행 · @학생·노트`.
- `/설명서` 명령: 결과 카드(kind 'help')에 명령·스킬·@·앱 단축키·노트 단축키 표.
- Ctrl+K 창: `@keyframes scroll-open`(scaleX 0→1, 가운데 기준), reduced-motion이면 없음.
- 테스트: suggest.test(기호 없음, ! 뒤 @ 학생), skills.test(!상담), run/handlers test(/설명서 카드).

### Task 2: AI 출결 자료
- `appContext`: 이번 달·이번 학기·올해 출결을 종류마다 `번호 이름 n건` 목록으로. 학기 경계는 설정의 학기 시작일, 없으면 3/1·8/1.
- 테스트: skillRun 또는 ai.test에서 학생 이름(가명) 목록이 들어가는지.

### Task 3: 달력
- 일정 상세(EventDetail): 내 일정은 고치기와 지우기를 하고, 받은 일정은 보기만.
- `kind?: '개인'|'업무'`, `place?`: 색 클래스 `ev-personal`과 `ev-work`.
- 스킬 일정 추천은 `place`를 뽑고, SuggestCard에서 고친다. 구글로 보낼 때 location을 붙인다.
- 테스트: CalendarPage(누르면 상세, 고치기, 지우기, 받은 일정은 고치기 없음), skills normalize(place), google 변환(location).

### Task 4: 전달사항
- 날짜 표시 규칙과 위치(오른쪽 끝). 날짜 칸이 깨지지 않게 줄 아래에 편다.
- '날짜별' 목록(앞날짜 먼저, 지난 날짜 접힘, 마우스 올리면 지우기, 되돌리기 5초).
- 끌기 손잡이로 순서 바꾸기(startPointerDrag, moveNotice/order).
- @노트 후보가 보이도록 고친다(원인 찾기).
- 테스트: NoticeTab(날짜 표시, 날짜별 목록, 끌기 순서, @ 후보).

### Task 5: 홈 노트함과 노트함 표시
- NoteBox 줄에 마우스를 올리면 '전달사항으로' 지정/해제(linkNoteToDate(today) / unlinkNoticeNote). 그날 짝 노트가 있으면 합치기·바꾸기를 묻는다.
- 노트함의 `[전달 11/13]` 작은 표, 줄 넓히기, 마우스 올리면 그라데이션과 고정·제거.
- 테스트: NoteBox, NotesPage.

### Task 6: 누가기록
- ExportMenu: 걸러 본 목록을 한글·엑셀·PDF로, 바로 인쇄.
- 대상 목록에서 '교사'를 뺀다(예전 값은 보임). 관찰에도 분야를 둔다. 고른 학생을 다시 누르면 선택이 풀린다. 미정리 알림 설정(`nuga_alert_off`).
- 테스트: CounselingPage 계열.

### Task 7: 결석 기간
- 출결 입력에서 결석일 때 '기간' 칸(끝일, 기본 시작일 = 1일). `schoolDaysBetween(db, from, to)`: 주말·휴업일을 뺀다. 미리 날 수를 보이고, 이미 있는 날은 덮어쓸지 묻는다.
- 테스트: attendance lib와 화면.

### Task 8: 노트
- 끌기를 위로 해도 되게 고친다(원인 찾기: dropIndex/reorder). 모든 목록을 점검한다.
- 표 너비(좁게·보통·넓게)와 칸 너비 끌기(`widths?`).
- / 메뉴 단축키 힌트, 명렬표 체크한 학생 줄이기와 모두 숨기기, 지우기 확인 단추 크기.
- 테스트: pointerDrag/reorder, NoteEditor 계열.

### Task 9: 확인과 배포
- 전체 테스트와 tsc, 캡처, opus 리뷰, 고치기, 0.14.0 배포.
