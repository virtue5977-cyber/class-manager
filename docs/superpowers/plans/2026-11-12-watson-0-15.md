# Watson 0.15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 설계서 13. 노트 편집기에 한글 같은 도구 막대, 표, 그림, 쪽 보기·쪽 나누기, 머리말·꼬리말을 더한다.
**Architecture:** 지금 블록 편집기를 그대로 쓰고 블록 종류와 선택 필드를 더한다. 쪽 나누기는 블록 높이를 재서 화면에 쪽 틈을 그리는 방식이다(저장하지 않음). exe와 DB 스키마 버전은 바꾸지 않는다.
**Tech Stack:** React 18, TS, Dexie, Vitest(jsdom), Playwright 캡처, hwpx(xml).
**Spec:** docs/superpowers/specs/2026-11-12-watson-0-15.md

## Global Constraints
- exe 무변경, 업데이트 shell 1, 판 0.15.0.
- 예전 노트(marks.size, 필드 없음)는 그대로 열린다. 새 값은 모두 선택 필드다.
- 캡처는 가상 자료만 쓴다.

## Review Focus
- 한글 조합 중에 도구 막대·표 칸·머리말 칸의 Enter·Tab·방향키가 끼어들지 않는다.
- 쪽 나누기 계산: 빈 노트, 쪽보다 큰 블록, 쪽 나누기 블록이 연달아 올 때, 확대 50%·200%.
- 그림: 큰 그림 줄이기, 지원하지 않는 형식, 지운 그림 파일(note_files 없음).
- 전달사항 연동(noteSync)은 표·그림·쪽 나누기 블록을 전달사항으로 만들지 않는다.
- 내보내기(hwpx·한글로 복사)에서 정렬·줄 간격·pt·표·그림·머리말·쪽 나눔이 빠지지 않는다.

---
### Task 1: 모양 값(pt·정렬·줄 간격)
- marks: `Style.pt?: number`(8~32, KEYS·okValue). `applyStyle` 값에 number를 받는다. `ptOf(style, base)`: pt ?? size(sm 0.85·lg 1.25 × base) ?? base.
- `styleCss`: pt → `calc(var(--pt, 1.5px) * N)`.
- 블록 `align?`, `line?`: 화면 css, toHtml(`text-align`, `line-height`), note-doc(문단 모양 Registry가 align·line·left를 키로).
- 테스트: marks.test(pt 값 검사·applyStyle), toHtml.test, note-doc.test(정렬 JUSTIFY/CENTER, lineSpacing 200).

### Task 2: 도구 막대(NoteToolbar)
- FormatBar를 대신한다. 커서 줄과 고른 범위(trackSel)를 바탕으로 상태를 보인다.
- 윗줄: 문단 모양 select, 수준 ▲▼, 표, 그림, 구분선, 쪽 나누기, 파일, 되돌리기·다시 하기.
- 아랫줄: 글꼴, pt(숫자·▲▼), 굵게·기울임·밑줄·취소선, 글자색, 형광펜, 정렬 4, 줄 간격.
- 고른 글이 없으면 글자 단추는 다음에 칠 글자에 적용(pending style: 다음 commit에 그 자리 새 글자에 적용).
- 테스트: NotesPage.test(줄을 고르고 가운데 정렬·200% 저장, 글을 골라 pt 14·굵게, 상태 표시).

### Task 3: 표 블록
- blocks: type 'table', `cells: string[][]`, `widths?`, `head?`, `tsize?`. lib `tableOps`: addRow(at), addCol(at), delRow, delCol, setCell, setWidths(정규화·최소 6%).
- TableBlock: textarea 칸, Tab·Shift+Tab·마지막 칸 Tab 새 줄, ↑↓ 칸 끝에서 위아래, 칸 경계 끌기, 도구(줄·칸 ±, 머리 줄, 지우기).
- 표 넣기 고르개(8×10).
- toHtml `<table>`, note-doc tableXml(머리 줄 굵게, widths).
- 테스트: tableOps.test, NotesPage.test(넣기·Tab·줄 더하기), note-doc.test.

### Task 4: 그림 블록
- type 'image', `file_id`, `width?`(%), `align?`, `caption?`. `attachImage(db, noteId, file)`: 형식 검사, 10MB, 2000px 넘으면 canvas로 줄임(jsdom에서는 건너뜀).
- 넣기: 도구 막대, 끌어놓기(그림이면 그림 블록·아니면 파일), Ctrl+V 그림.
- 모서리 끌기로 너비.
- toHtml `<img src=data:>`(복사 때 파일 읽기), note-doc BinData(hwpx package에 그림 넣기).
- 테스트: images.test, NotesPage.test(붙이기·너비), note-doc.test(BinData·pic).

### Task 5: 쪽
- NoteRec `page?`. 도구 막대 '쪽' 메뉴: 쪽 보기, 여백, 격자, 머리말·꼬리말.
- `paginate(heights: number[], forced: boolean[], pageH: number): number[]`(각 쪽 첫 블록 index). 화면은 쪽 보기일 때 블록 앞에 쪽 틈(머리말·꼬리말 포함)을 끼운다. ResizeObserver로 다시 잰다.
- 'pagebreak' 블록.
- 머리말·꼬리말 `{쪽}` `{전체쪽}` `{날짜}`.
- 확대 50~200%.
- 인쇄 CSS: 쪽 보기 모양, 격자 빼기.
- hwpx: 여백(pagePr margin), 머리말·꼬리말(hp:header/footer, 쪽 번호 autoNum), pageBreak="1".
- 테스트: paginate.test, NotesPage.test(쪽 보기 켜기·머리말 저장), note-doc.test(여백·머리말·pageBreak).

### Task 6: 확인과 배포
