# Watson 0.18 화면 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** 화면마다 다른 글자·단추·아이콘을 한 기준으로 맞추고, 빈 화면·몇몇 화면을 정리하고, AI 가명을 보완한다.
**Spec:** docs/superpowers/specs/2026-11-13-watson-0-18.md

## Global Constraints
- exe 변경 없음. 기능·이름표(aria-label) 그대로(시험이 이름표로 찾음).
- 가상 자료만으로 캡처.

## Review Focus
1. 토큰 치환 뒤 어두운 화면·인쇄·노트 종이(.note-paper)·반성문 용지 글자 크기가 바뀌지 않아야 함(용지 미리보기는 pt 계산값).
2. 아이콘 단추에 이름표가 남아 있어 화면 낭독기·시험이 그대로 찾음.
3. 달력 일정 추가를 접어도 날짜 클릭→추가 흐름, AI 일정 제안 흐름이 그대로.
4. 홈 칩이 입력칸 내용을 덮어쓰지 않음(빈 칸일 때만 채움 또는 커서 위치).
5. 보호자 가명이 되돌리기에서 원래 이름으로 돌아옴.

### Task 1: AI 가명 보완 — mask.ts(`maskText(text, names, map, roles?)`: 보호자 이름 목록은 `보호자A`), `allStudentNames`는 그대로 쓰되 가명용 `maskTargets(db)` = { students, guardians }; nuga.ts 순번 id; skillRun 출결 맥락 `who()`는 가리기 켜짐이면 번호 없이 이름만.
### Task 2: 아이콘 — Icon에 chevronLeft/Right/Up, close, arrowUp/Down/Left, more, mic, alert, paperclip, panelLeft/Right, twisty 추가; 목록의 기호를 바꿈; `src/ui-glyphs.test.ts`가 금지 기호를 소스에서 찾는다.
### Task 3: 토큰 — `:root`에 --fs-*, --r-*, --h-*; 스크립트로 CSS 값 치환(11·11.5·10.5→12, 12.5→13, 14.5→14, 16·18→17, 22→24; 반지름 2·3→4, 9·10→8, 14→12, 9999→999; 단추 높이 30→32, 36→40, 24 단추→28); 실측 전후 비교.
### Task 4: 빈 화면 — 누가기록 0건 안내, 홈 칩(`/출결`, `/상담`, `/일정`, `/할일`, `!전달`, `/설명서`).
### Task 5: 화면별 — 달력 접기, 자리배치 사용법, 청소 아이콘 단추, 반성문 더 메뉴, 설정 점 설명.
