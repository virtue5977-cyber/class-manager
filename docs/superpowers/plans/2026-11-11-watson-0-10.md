# Watson 0.10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** 설계서 8을 화면 쪽만 바꿔 반영한다(exe 그대로).

**Architecture:** 끌기는 공용 포인터 끌기 함수 하나(`src/lib/ui/pointerDrag.ts`)로 만들고, 할 일과 노트함이 함께 쓴다. 순서는 `order` 선택 필드에 저장한다. 아이콘은 `Icon`에 경로를 더한다.

**Tech Stack:** React 18, TS, Dexie, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-11-11-watson-feedback-0-10.md

## Global Constraints
- exe를 바꾸지 않는다. 캡처에는 가상 자료만 쓴다. 판은 0.10.0이다.

## Review Focus
- 끌기와 클릭을 구분한다(5px 문턱). 끌고 나서 놓을 때 노트가 열리면 안 된다.
- 순서를 바꾸고 폴더를 옮길 때 지운 노트나 다른 폴더 노트의 order를 망가뜨리면 안 된다.
- 옛 layoutPrefs에는 notice 칸이 없다. 이때는 왼쪽 탭에 생겨야 한다.
- 전체 지우기는 되돌릴 수 있어야 하고, 그날 보이는 항목만 지워야 한다.
- 요약 줄의 방학 D-day: 지난 방학, '방학식' 같은 일정, 없을 때를 처리한다.

### Task 1: 아이콘 + 대답 아래 작은 아이콘 + 좁은 대화
- Icon에 folder, plus, pencil, trash, copy, noteAdd, download, upload, printer, chevronDown, grip을 더한다.
- ResultCard: '복사'·'노트로' 글자 대신 카드 아래 `.result-icons`에 아이콘 단추(aria-label 복사/노트로)를 둔다.
- CSS: .chat-log에 container-type:inline-size, @container (max-width:520px)를 쓴다.

### Task 2: 포인터 끌기 + 할 일 순서
- `pointerDrag.ts`: `startPointerDrag(e, { threshold=5, onMove(x,y), onDrop(x,y), onCancel })`. Esc는 취소.
- `dropIndex(ys: number[], y): number`. 테스트를 쓴다.
- TodoList: 손잡이를 끌면 줄 사이에 선을 보여 주고, 놓으면 `reorderTodos(db, ids)`로 저장한다. lib 테스트를 쓴다.

### Task 3: 노트함 나무(아이콘·줄 맞춤·끌기·순서·폴더 도구)
- `reorderNotes(db, folderId, ids)`: 그 폴더의 노트 order를 0..n으로 다시 매기고, 옮겨 온 노트의 folder_id도 바꾼다. listNotes는 고정 → order → 최근 순으로 정렬한다. 테스트를 쓴다.
- NotesPage: HTML DnD를 없애고 포인터 끌기로 바꾼다. 놓는 곳이 폴더 줄이면 moveNote, 노트 줄 사이면 reorderNotes, 폴더를 다른 폴더에 놓으면 moveFolder.
- 줄 구조: [들여쓰기][▸ 칸 16px][아이콘 16px][이름][도구]. 폴더 도구는 + 새 노트, ✎, 🗑.
- NoteBox: 아이콘, 줄, 10개. 넓은 칸이면 날짜와 미리보기를 보여 준다.

### Task 4: 전달사항 칸 자리 + 머리 아이콘 + 전체 지우기 + 바로 인쇄
- PanelKey에 'notice'를 더한다(기본 자리 tab). HomePage 탭은 대화 + 탭 칸들로 만든다.
- NoticeTab 머리는 아이콘 단추: 가져오기(upload), 노트로(noteAdd), 내보내기(download 아이콘 메뉴), 전체 지우기(trash). `clearNoticesOn(db, date)`가 되돌리기를 돌려준다. 테스트를 쓴다.
- ExportMenu에 '바로 인쇄'(window.print) 항목과 `icon` 속성(아이콘만 쓰는 단추)을 둔다.

### Task 5: 홈 위쪽 배치 + 요약 줄
- HomePage: 두 열 grid. 왼쪽은 머리·시작하기·탭·대화, 오른쪽 aside는 맨 위부터.
- TodaySummary: 내 수업 · 방학 D-day · 출결 · 미제출 신고서 · ▾. `vacationDday(cal, today)` 테스트를 쓴다. 펼치면 출결 상황, 시간표, 급식을 보여 준다.

### Task 6: 달력 일요일 시작
- CalendarPage: DAYS를 일요일부터로 바꾸고 칸 시작 offset을 고친다. 테스트를 고친다.
