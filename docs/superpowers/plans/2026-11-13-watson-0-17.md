# Watson 0.17 안전 보강 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 자료를 잃거나 새게 하는 구멍을 exe 변경 없이 막는다.
**Architecture:** 백업 형식 번호를 Dexie 판과 분리하고 부분 복원을 허용한다. 저장 미룸은 공용 flush 등록부로 닫힐 때 비운다. 가리기는 mask.ts 한 곳에서 넓힌다.
**Tech Stack:** React 18, TS, Dexie 4, Vitest + Testing Library.
**Spec:** docs/superpowers/specs/2026-11-13-watson-0-17.md

## Global Constraints
- exe(electron/) 변경 없음. 화면 문구는 한국어, '지우기'.
- 실제 학생 자료 사용 금지(시험·캡처는 가상 자료).
- 각 작업: 실패 시험 먼저 → 구현 → 해당 시험 통과 → 커밋.

## Review Focus
1. 옛 형식(1) 백업을 새 앱에서 복원: 백업에 있는 표만 바뀌고 없는 표는 남아야 함.
2. 새 앱이 만든 형식 2 백업을 옛 앱(0.16)이 열면 '새 버전 백업' 오류로 거절(자료 안 바뀜).
3. 자동 백업 타이머와 창 보임 이벤트가 겹쳐도 백업 한 번.
4. 첨부 정리: 다른 노트로 잘라 붙인 그림, 되돌리기로 살린 그림은 지워지지 않음.
5. 한글 조합 중 Enter가 제목에서 본문으로 튀지 않음.

### Task 1: 백업 형식 번호 분리 + 부분 복원 (A1, A2)
**Files:** `src/lib/db/schema.ts`, `src/lib/backup/snapshot.ts`, test `src/lib/backup/snapshot.test.ts`
- `BACKUP_FORMAT_VERSION = 2`, `BACKUP_TABLES_BY_VERSION: Record<number, readonly string[]>` (2 = 현재 SYNCED_TABLES). Dexie는 `this.version(1)` 숫자로.
- 시험: `SYNCED_TABLES`가 `BACKUP_TABLES_BY_VERSION[BACKUP_FORMAT_VERSION]`과 같다(표를 더하면 형식 번호를 올리라는 메시지).
- `MIGRATIONS[1] = (s) => ({ ...s, schemaVersion: 2 })` (표 구성은 그대로; 없는 표는 그냥 없음).
- `importSnapshot`: `Object.hasOwn(s.tables, t)`인 표만 clear+bulkAdd.
- 시험: notes가 없는 v1 스냅샷 복원 → 기존 노트 남음, classes는 바뀜. v3 스냅샷 → BackupVersionError.
