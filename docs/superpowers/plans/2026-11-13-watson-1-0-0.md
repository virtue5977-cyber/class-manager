# Watson 0.18.1 + 1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 옛 exe 지킴이(0.18.1)를 낸 뒤, 학생 자료 전체 암호화·옮기기·구글로 시작·exe 보강을 담은 새 exe(SHELL 7)와 렌더러 1.0.0을 낸다. 드라이브 동기화(1.0.x)가 exe를 다시 내지 않도록 메인 API를 모두 미리 넣는다.

**Architecture:**
- 렌더러: Dexie DBCore 미들웨어(동기 AES-GCM)로 새 DB `watson-<keyId8>`를 암호화한다. `VaultGate`가 열쇠를 푼 뒤에만 `AppProviders`를 붙인다.
- 메인: 열쇠 감싸기(safeStorage 비동기)·구글 API 통로·업데이트·권한을 맡는다. 순수 로직은 `electron/*.cjs` 모듈로 떼어 Vitest(node)로 시험한다.

**Tech Stack:** React 18, TS, Vite, Dexie 4.4, Vitest + fake-indexeddb, Electron 44.10.2, electron-builder 25.1.8, @noble/ciphers 2.4.0, @electron/fuses.

**Spec:** docs/superpowers/specs/2026-11-13-watson-1-0.md (3판). 드라이브 동기화(§7)는 이 계획 밖이며 별도 계획(1.0.x)으로 간다. 단 §10 메인 API는 여기서 다 만든다.

## Global Constraints
- 화면 문구는 한국어. 지우는 단추는 '지우기'.
- 실제 학생 자료 금지: 시험·캡처는 가상 자료만.
- 비밀 서명 열쇠 `/home/claude/keys/damim-update-private.pem`은 배포 명령에만 쓰고, 출력하거나 읽지 않는다.
- 암호문 형식 v1: `0x01 ‖ iv(12) ‖ AES-256-GCM`, 행 aad `watson-row:v1:<표>:<id>`, 블롭 aad `watson-blob:v1:<id>`, DEK 감싸기 aad `watson-dek:v1:<pass|recovery>:<keyId>`, 확인값 aad `watson-check:v1`.
- PBKDF2-SHA256: 암호구 600,000회, 복구 코드 100,000회. 복구 코드는 25자(5×5), 문자 집합 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`.
- 새 DB 이름 `watson-<keyId 앞 8자>`, 옛 DB `class-manager`.
- 미들웨어 단계 3. `Table.hook` 금지.
- 로그에 행 내용·이름·토큰을 쓰지 않는다.

  - query·openCursor는 `values`에서 손상 행을 뺀다. 커서는 `value` getter로 감싼다.
- `src/lib/db/records.ts` `save()`: vault DB에서는 쓰기 뒤 `lastStamp`를 반영해 돌려준다.
