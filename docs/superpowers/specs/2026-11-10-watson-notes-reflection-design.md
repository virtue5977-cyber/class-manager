# 설계서 3 — 노트함 · 전달사항 · 반성문 · 할 일 노트 연결

상태: 승인(11/10, "문서 탭은 다음 버전, 일단 완성") · 근거: 문서 '설계서' 탭의 설계서 3 · 설계서 2(명령 홈)와 함께 만든다. 설계서 4(문서 작성)는 다음 버전.

설계서 2 §6의 `notes(kind '전달'|'메모')`는 이 설계로 대신한다: 전달사항과 노트를 나눈다.

## 1. 노트함
- 화면 `#/notes`(사이드바 '노트함', 홈 오른쪽 패널에도 최근 노트 5개). 왼쪽 노트 목록(찾기 · 고정 · 지우기, 첨부 있으면 클립 표시) + 오른쪽 편집.
- 노트 = 제목 + 블록 목록. 블록 종류: 문단 · 제목1 · 제목2 · 체크 · 글머리 · 번호 · 구분선 · 파일 · 폴더. (표·학생칩·날짜칩은 다음에.)
- 빈 블록에서 `/` → 블록 메뉴(↑↓ Enter Esc, 한글 이름으로 거르기). Enter = 다음 블록, 빈 블록에서 Backspace = 지우고 위로. 블록 왼쪽 손잡이: 끌어서 순서 바꾸기, 메뉴(전달사항으로 보내기 · 복사 · 지우기).
- 첨부: 파일을 끌어다 놓거나 `/파일` → 파일 블록(이름·크기, 누르면 내려받기·열기). 한 파일 50MB까지. 내용은 앱 자료와 함께 보관, 암호화 백업에 포함.
- 폴더: `/폴더` → 노트북 폴더 경로만 연결(복사 안 함). 누르면 탐색기로 열기, 펼치면 안의 파일 이름 목록. 새 exe(SHELL 4)에서만, 아니면 '새 exe가 필요합니다'.
- 보내기: 노트 전체 또는 블록 → 전달사항(기간 고르기). 반성문·대화 결과 → 새 노트(원래 화면 링크 블록 포함).
- 내보내기 ▾: 한글(제목·문단·목록) · PDF · 엑셀(체크·목록 블록만 한 줄씩).

## 2. 전달사항
- 항목: 내용 · 시작일 · 끝일(하루면 같음) · 완료 · 고정(핀) · 순서.
- 어떤 날짜 D에 보이는 항목 = 시작 ≤ D ≤ 끝. 정렬: 고정 먼저 → 순서 → 완료는 아래(흐리게).
- 홈: 그날 항목이 있으면 대화 영역 위에 '전달사항 n' 탭(없으면 탭 없음). 탭: 체크 · 지우기(10초 되돌리기) · ↑↓ 순서 · 핀 · 기간 고치기 · 직접 추가 · '붙여넣어 AI로 나누기'(기존 브리핑 정리 재사용) · 노트로 보내기 · 내보내기(한글·엑셀·PDF).
- 옮기기: 기존 briefings(조례·종례) 항목 → 전달사항(그날 하루, 조례 먼저 순서). 한 번만(device_local 표시), briefings는 그대로 둔다.

## 3. 반성문 (학급 > 반성문)
- 보내 준 생성기의 맞춤 규칙을 그대로 옮긴다: 16줄, 위 안내 2줄(기본 문장 그대로), 넘치면 자간(기본 -1%→최소 -15%) → 글자 크기(최소 10pt) 순으로 줄여 한 줄에, 그래도 넘치면 빨간 표시. 붙여넣은 글을 문장 단위로 16줄에 나누기(번호 '1.' 지움). B4/A4. hwpx는 보내 준 양식의 글자만 바꿔 저장.
- 고친 점: 글자 폭은 함초롬돋움 폭 표(앱에 넣음)로 잼(글꼴 없는 노트북에서도 한글 결과와 같게) · 학생을 고르면 날짜(오늘 2026.11.10.)·학번(학년반번호 5자리)·이름 자동 · JSZip은 앱 것 · 테마 색 · PDF 저장 때 용지 크기 넘김 · 저장 기록.
- 화면: 머리(제목 '반성문', 요약 '이번 학년도 n건', 내보내기 ▾ 한글·PDF·엑셀=목록) · 왼쪽 학생 목록(명단과 같은 모양, 아래 그 학생 지난 반성문) · 가운데 양식 미리보기(축소, 줄을 누르면 그 자리에서 고침, 넘친 줄 빨간 밑줄) · 오른쪽 접는 칸(사유 · AI로 16줄 채우기 · 붙여 넣어 나누기 · 좋은 문장 모음 · 맞춤 설정 · 위 안내 2줄). 종이는 어둡게 테마에서도 흰색.
- AI: 사유만 보냄(이름·학번 안 보냄). 지시문은 화면에서 고치고 '기본으로 되돌리기'(ai_prompts kind 'reflection'). 응답은 16줄(JSON 배열).
- 좋은 문장 모음: 줄·전체에 별표 → 모음. 처음엔 기본 16문장. '모음에서 넣기'로 고른 줄에 넣음.
- 저장: 학생·날짜·사유·16줄·안내 2줄·용지. 상담일지 그 학생 화면에 '반성문 n건' 한 줄(누르면 반성문 화면). 노트로 보내기.

## 4. 할 일 노트 연결
- 할 일 글에서 `@` → 학생과 노트 제목이 함께 후보(노트는 문서 아이콘). 고른 노트는 링크 조각으로 저장(노트 id), 보일 때는 지금 노트 제목, 누르면 그 노트. 지운 노트는 흐린 글자.
- 노트 화면 위에 '이 노트를 가리키는 할 일' 목록(체크 가능).

## 5. 자료(DB v3, 백업 포함)
- `notice_items`: text, start_date, end_date, done, pinned, order.
- `notes`: title, blocks[{id, type, text?, checked?, file_id?, path?}], pinned, updated_at.
- `note_files`: note_id, name, mime, size, data(base64).
- `todos`: parts[(string | {note: id} | {student: id})], due?, done, done_at?, order.
- `reflections`: student_id, date, reason, lines[16], t1, t2, mode('B4'|'A4').
- `reflection_phrases`: text, starred_at.
- 설계서 2의 `chat_log`, `local_events`도 여기서 만든다.

## 6. 시험
- 단위: 전달사항 날짜 판단·정렬·옮기기, 블록 편집 연산(나누기·합치기·옮기기·바꾸기), 할 일 조각 저장·표시, 반성문 맞춤(폭 표로 계산)·나누기·hwpx 글자 바꾸기·AI에 이름 안 감, 첨부 크기 제한.
- 화면 캡처(기본·어둡게): 노트함·`/` 메뉴·첨부, 전달사항 탭, 반성문.

## 7. 하지 않는 것
- 문서 작성 메뉴(설계서 4, 다음 버전), 노트 표·칩 블록, 노트 공유.
