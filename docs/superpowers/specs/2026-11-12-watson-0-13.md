# 설계서 11: Watson 0.13

출처: 사용자 11/12 요청(17항목 중 7·8·9·10·13번 + 11/12 추가 1~6번).
exe는 바꾸지 않는다(업데이트 shell 1). 자동 실행 단추는 큰 exe 업데이트 목록으로 미룬다.
저장 형식은 선택 필드만 더한다. 예전 백업과 기록은 그대로 읽힌다.

## 1. 채팅: 바로 올라가기와 기다림 표시
- Enter를 누르면 내 말이 곧바로 대화 목록에 올라간다. 입력칸은 비운다.
- 결과가 오기 전까지 시스템 말풍선에 점 세 개(● ● ●)가 차례로 깜박인다.
  - 이 말풍선에는 aria-label "대답을 만드는 중"을 붙인다.
  - 움직임 줄이기 설정(prefers-reduced-motion)이면 깜박이지 않는 '…'만 보인다.
- 결과가 오면 그 자리에서 결과 카드로 바뀐다. 실패하면 그 자리에 오류 문구와 '다시 보내기'가 뜬다.
- 규칙 명령(`/`)처럼 바로 끝나는 것은 점이 거의 보이지 않아도 된다. 300ms 안에 끝나면 점을 그리지 않는다.
- 기다리는 동안 다른 말을 보내면 줄을 서서 차례로 처리한다.

## 2. 노트 편집기
### 2-1. 줄바꿈 버그
- 한 줄 글이 칸 너비를 넘으면 옆으로 늘어나지 않고 다음 줄로 넘어가야 한다. 1366·1024·800px에서 캡처로 확인한다.
- 긴 영문·URL(띄어쓰기 없는 글)도 칸 안에서 끊긴다(overflow-wrap:anywhere).

### 2-2. 글자 서식
- 글 블록(문단·제목·목록·체크) 안에서 글자 일부를 골라 서식을 준다.
  - 굵게: Ctrl+B
  - 밑줄: Ctrl+U
  - 기울임: Ctrl+I
  - 취소선
  - 글자색: 8색
  - 형광펜: 5색
  - 글꼴: 기본, 맑은 고딕, 함초롬바탕, 함초롬돋움, 나눔고딕, 바탕, 돋움, 굴림, 궁서
  - 글자 크기: 작게, 보통, 크게
- 글을 고르면 그 위에 작은 서식 막대가 뜬다. Esc를 누르거나 다른 곳을 누르면 닫힌다.
- 저장 방식:
  - 블록의 `text`(서식 없는 글)는 그대로 둔다. 찾기, 미리보기, 전달사항, AI는 지금처럼 `text`만 쓴다.
  - 서식은 선택 필드 `marks?: Mark[]`에 둔다.
    - `Mark = {from, to, b?, u?, i?, s?, color?, bg?, font?, size?}`
    - from과 to는 `text` 안의 글자 위치다.
  - 글을 고치면 marks의 위치를 같이 옮긴다.
    - 앞에 글을 넣으면 뒤로 민다.
    - 지운 구간은 줄이거나 없앤다.
    - 줄을 나누거나 합치면 marks도 나누거나 합친다.
- 편집기는 서식이 보이는 contentEditable 줄로 바꾼다. 모든 붙여넣기는 서식 없는 글로 받는다. 이유: 외부 HTML이 들어오지 않게 하려는 것이다.
- 지원하는 글꼴이 PC에 없으면 비슷한 기본 글꼴로 보인다. 함초롬체는 한글을 깔면 들어 있다.

### 2-3. 노트 단축키 정리
지금 단축키의 문제:
- Ctrl+Shift+숫자: Windows 한글 자판에서는 Ctrl+Shift가 입력기 전환과 겹친다. Ctrl+Shift+0은 Windows가 먹는 경우가 있다.
- Ctrl+Alt+숫자: 일부 자판에서 AltGr로 읽힌다.
- 노트 안에서 Ctrl+숫자를 누르면 메뉴 이동이 되어 노트를 떠나 버린다.

바꾼 단축키(한글 프로그램처럼):
- 노트 글 안에 초점이 있을 때, Ctrl+숫자는 메뉴 이동 대신 줄 모양을 바꾼다.

| 단축키 | 줄 모양 |
|---|---|
| Ctrl+1 | 문단 |
| Ctrl+2 | 제목 1 |
| Ctrl+3 | 제목 2 |
| Ctrl+4 | 글머리 목록 |
| Ctrl+5 | 번호 목록 |
| Ctrl+6 | 체크 목록 |

- Ctrl+Enter: 체크 목록 줄의 체크를 켜고 끈다.
- Tab / Shift+Tab: 들여쓰기와 내어쓰기(지금처럼).
- Ctrl+B / U / I: 서식.
- 줄 맨 앞에 쓰는 `#`, `##`, `-`, `1.`, `[]` 뒤 띄어쓰기는 그대로 둔다.
- Ctrl+Shift·Ctrl+Alt 숫자는 한 판 동안 계속 받는다(손에 익은 사람을 위해서다). 단축키 표에서는 뺀다.
- 노트 밖에서는 Ctrl+숫자가 지금처럼 메뉴 이동이다.
- 단축키 표와 슬래시 메뉴의 힌트를 새 단축키로 고친다.

### 2-4. 한글로 복사
- 노트 머리의 '한글로 복사' 단추, 또는 일부를 골라 Ctrl+C.
- 클립보드에 text/html과 text/plain을 함께 넣는다. 한글에 붙여 넣을 때 다음이 남아야 한다.
  - 제목 크기와 굵기
  - 글머리표·번호
  - 체크(☐/☑)
  - 들여쓰기
  - 글자 서식(굵게·밑줄·기울임·취소선·색·형광펜·글꼴·크기)
  - 학생 체크 표(테두리 있는 표)
- 확인 방법: 가상 노트 5종을 만든다(공지, 체크리스트, 명단 표, 긴 글, 서식 섞인 글).
  - 화면 캡처를 찍는다.
  - 같은 HTML을 hwpx로 바꿔 본 결과를 캡처해서 보여 준다. 실제 한글에 붙여 넣는 것은 사용자가 Windows에서 확인한다.

### 2-5. '노트 전체를 전달사항으로' 위치
- 제목 아래 줄에 있던 이 단추를 제목 줄 오른쪽 끝으로 한 칸 올린다.

## 3. 노트 ↔ 전달사항 연동
### 3-1. 하루 전달사항 = 노트 한 장
- 날짜마다 짝이 되는 노트가 하나 있을 수 있다(`NoteRec.notice_date?: string`).
  - 제목은 `[전달사항] 11/13(금)`이다.
  - 노트함에서 [전달사항] 표가 붙는다.
  - 오늘과 앞날짜의 전달사항 노트는 노트함 맨 위(고정 노트보다도 위)에 둔다. 지난 날짜의 노트는 보통 노트처럼 정렬한다.
- 짝 노트가 생기는 때:
  - 전달사항 칸에서 '노트로 열기'(📄 아이콘)를 누를 때. 그날 짝 노트가 없으면 만들고 연다.
  - 노트에서 '노트 전체를 전달사항으로'를 누를 때. 기간을 고르는 대신 그 노트를 고른 날짜의 짝 노트로 정한다. 그날 이미 짝 노트가 있으면 합칠지 바꿀지 묻는다.
- 맞추는 규칙:
  - 노트의 글 블록 한 줄 = 전달사항 한 항목이다. 같은 순서를 쓰고, 체크는 '했음'과 같다.
  - 전달사항 항목에 `block_id?`를 두어, 어떤 노트 줄과 짝인지 기억한다.
  - 노트에서 줄을 더하거나 고치거나 지우거나 옮기면, 저장할 때 그날 전달사항도 똑같이 바뀐다.
  - 전달사항에서 줄을 더하거나 고치거나 지우거나 옮기거나 체크하면, 짝 노트도 똑같이 바뀐다.
  - 제목 줄, 구분선, 파일, 표 블록은 전달사항 항목이 되지 않는다. 노트에만 남는다.
  - 여러 날에 걸친 전달사항(start ≠ end)은 짝 노트에 넣지 않는다. 전달사항 칸에서만 보인다.
  - 두 쪽이 동시에 바뀌면 나중에 저장한 쪽이 이긴다. 맞추기는 한 트랜잭션 안에서 한다.
- 짝 노트를 지우면 그날 전달사항은 남기고 연결만 끊는다. 짝을 풀 때는 노트 머리의 '전달사항 연결 끊기'를 누른다.
- 날짜가 지나면 지난 전달사항은 지금처럼 그날 화면에서만 보인다. 노트는 남는다.

### 3-2. @노트 링크
- 전달사항 글과 노트 글 안에서 `@`를 치면 할 일처럼 노트 후보가 뜬다. 고르면 노트 링크가 된다.
- 저장 방식:
  - 전달사항: `parts?`(할 일과 같은 형식)
  - 노트 블록: `links?: {from, to, note}[]`
- 링크는 평소 글처럼 보이다가 마우스를 올리면 밑줄과 강조색이 생긴다. 누르면 그 노트가 열린다.
- 지운 노트를 가리키는 링크는 흐린 글로 남는다.
- 짝 노트 ↔ 전달사항 맞추기에서도 링크가 따라간다.

## 4. 누가기록
- 메뉴 이름 '상담일지'를 '누가기록'으로 바꾼다. 주소(/counseling)와 단축키 순서는 그대로다.
- 기록에 `kind?: '상담' | '관찰'`을 둔다. 값이 없으면 상담이다.
  - 관찰 기록은 날짜, 시각, 장소, 내용만 입력한다.
- 기본 화면은 전체 기록 목록이다.
  - 최근 순으로 날짜, 종류, 학생(번호 이름), 첫 줄, 정리 상태를 보여 준다.
  - 거르기: 종류, 학생, 기간, 정리 상태.
  - 줄을 누르면 그 기록을 연다.
  - 학생을 고르면 지금처럼 학생별 화면이 나온다.
- 명령:
  - `/관찰 @번호 내용`을 새로 둔다.
  - `/상담`은 그대로다.
  - `!누가`는 상담과 관찰을 모두 본다.
- AI 누가기록 정리:
  - 관찰 기록도 정리 대상이고, '나이스 입력 완료' 표시를 쓴다.
  - 머리줄은 앱이 붙인다. 순서: 일자 → 시각 → 장소 → (상담이면 대상·방법) → 내용.
  - 빈 항목은 빼고, 머리줄에 아무것도 없으면 내용만 쓴다.
  - 기본 지시문에도 이 순서를 적는다.
- 학급 명단 상세: 학생 정보 아래에 그 학생의 누가기록 목록(최근 10개, '모두 보기')과 '+ 기록' 단추를 둔다.

## 5. 바탕화면 바로가기·자동 실행 (exe 무변경)
- 설정 → 앱(데스크톱판에서만 보인다)에 '바로가기·자동 실행 도우미'를 둔다.
- 받기 단추가 두 개 있다.
  - '바로가기 만들기(.cmd)': 바탕화면 바로가기와 시작 프로그램 바로가기를 만든다.
  - '자동 실행 끄기(.cmd)': 시작 프로그램 바로가기를 지운다.
- 도우미 파일이 하는 일:
  - PowerShell로 사용자 폴더 안(바탕화면, 다운로드, 문서, 그리고 그 아래 3단까지)에서 Watson.exe를 찾는다.
  - 여러 개 나오면 가장 최근에 고친 것을 쓴다.
  - 하나도 없으면 "Watson.exe를 찾지 못했습니다"를 띄운다.
  - 다른 곳에는 손대지 않는다.
- 같은 칸에 손으로 하는 방법도 적는다: Win+R → `shell:startup` → 열린 폴더에 Watson 바로가기를 넣는다.
- 큰 exe 업데이트 때 진짜 켜기/끄기 단추로 바꾼다(미룸 목록).
