# 설계서 9: 0.11 — 다른 학교 양식 인식, 구글 Gemini 연결, 홈 정렬, 명단 기본 표

## 1. 다른 학교 양식 인식
원인(분석): 이름표에 쌍점·괄호가 붙어 있다(`학 번:`, `사 유(학부모 의견)`). 값이 채워진 예시 칸은 값 칸으로 쓰지 않는다. ◯ 표시 칸을 모른다. 표 밖 날짜 줄을 읽지 않는다. 명단에 없는 이름은 AI로 그대로 간다.
- 사용자가 채워 올린 양식은 '어디에 무엇이 들어가는지 보여 주는 예시'다. 예시 글이 든 칸을 그 자리의 값 칸으로 쓰고, 그 글은 {{표시}}로 바꾼다.
- 이름표 비교는 띄어쓰기·끝 쌍점·괄호 설명·윗첨자 숫자를 뗀 글로 한다.
- 값 칸 = 이름표 오른쪽(없으면 아래) 칸이 비었거나 '이름표가 아닌 글'이 든 칸. 그림·도형 칸은 쓰지 않는다. 바꿀 때는 칸의 글을 모두 지우고, 첫 문단에 {{표시}}를 넣는다.
- ◯ 표시 자리: 질병·인정·미인정·기타, 결석·지각·조퇴·결과 이름표 바로 아래 칸(비었거나 ◯·○·● 등). 새 표시는 {{표시_질병}}, {{표시_인정}}, {{표시_미인정}}, {{표시_결석}}, {{표시_지각}}, {{표시_조퇴}}, {{표시_결과}}다. 해당하면 ◯, 아니면 빈칸.
- 표 밖 날짜 줄(`2026년 11월 11일` 꼴)은 고를 수 있게 하고, 고르면 {{작성날짜}}로 바꾼다.
- 확인 화면의 칸 고르기에 '(지금: 예시 글)'을 보여 준다.
- AI에는 값 칸(이름표 바로 옆 칸)의 글을 `[값]`으로 바꿔 보낸다. 명단 이름도 가린다.
- 테스트는 사용자 예시와 같은 구조의 가상 양식(가상 이름)으로 한다. 받은 파일은 저장소에 넣지 않는다.

## 2. 구글 Gemini(API 키) 연결
- 설정 > AI 연결 방식에 'Google Gemini(API 키)'를 더한다. 키는 기기에만 저장하고, HTML판은 메모리에만 둔다(Claude 키와 같다).
- 모델은 `gemini-3.6-flash`(기본)와 `gemini-3.5-flash-lite`(빠름) 중에서 고른다. 둘 다 구글 모델 문서의 안정판이다.
- REST 호출: `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`, 헤더 `x-goog-api-key`. 오류 문구에는 키와 본문을 넣지 않는다.
- 구글 연결일 때는 학생 이름을 늘 가린다(effectiveMask).
- exe의 CSP connect-src에 구글 주소를 더한다. SHELL은 6, preload는 `desktop.shell = 6`. 옛 exe에서 구글을 고르면 '새 설치형 필요'를 안내한다. 업데이트 매니페스트는 shell 1을 유지한다(다른 기능은 옛 exe에서도 된다).

## 3. 홈 정렬
- 오른쪽 열 첫 칸(할 일)의 위쪽을 왼쪽 날짜 제목(h2) 위쪽과 같은 높이로 맞춘다.

## 4. 학급 명단 기본 표
- 명단 화면 기본: 명단 양식의 칸 순서대로 전체 학생 표를 보여 준다(번호·이름·학번·성별·보호자 등, 보이는 칸만).
- 왼쪽 학생 목록에서 학생을 누르면 그 학생 상세로 가고, 같은 학생을 다시 누르면 기본 표로 돌아온다(출결 화면과 같은 방식).
