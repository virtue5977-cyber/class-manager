# 설계서 1 — Watson 앱 틀 (메뉴·이름·단축키·내보내기)

상태: 검토 대기 · 근거: 문서 '홈 개편 기획안' 7·9장(11/10 확정), '2차 검토' 공통-1~5·학급-2·3·품질-1

## 1. 목표
- 앱 이름을 Watson으로 바꾸고, 메뉴를 하위 메뉴가 있는 구조로 바꾼다.
- 어느 화면에서나 단축키로 움직이고, 표가 있는 화면은 같은 '내보내기 ▾'(한글·엑셀·PDF)를 쓴다.
- 기존 자료(IndexedDB·백업 폴더·구글 로그인)는 그대로 이어진다.
- 성공 기준: 새 exe 설치 후 기존 학생·기록이 그대로 보이고, 모든 기존 화면이 새 주소에서 열리며, 단축키 표의 모든 키가 동작한다.

## 2. 이름과 exe (새 exe 한 번 — SHELL 3)
- package.json `productName`: Watson, exe `Watson.exe`, 창 제목·작업표시줄 Watson, 아이콘 W(256px .ico를 스크립트로 생성).
- **자료 보존**: Electron은 productName으로 userData 폴더를 정하므로, main.cjs에서 `app.setPath('userData', path.join(app.getPath('appData'), '담임업무'))`를 ready 전에 고정한다. 옛 폴더가 없으면(새 설치) 'Watson'을 쓴다. `appId`는 바꾸지 않는다.
- SHELL=3: `pdf:save` IPC 추가(webContents.printToPDF, A4, 저장 위치 대화상자). 렌더러는 브리지가 없으면 `window.print()`로 대신한다(HTML판·옛 exe).
- 업데이트 번들은 shell 1에서도 돌아가야 하므로 새 기능은 브리지 유무를 확인해 쓴다.

## 3. 사이드바
- 맨 위: **Watson** / 학교명(설정의 school_name, 없으면 생략) / '2026학년도 1학년 5반'. 학급이 둘 이상이면 이 줄을 눌러 고르는 목록(지금 학급 전환을 흡수).
- 메뉴(주소):
  - 홈 `/`
  - 달력 `/calendar`
  - 출결 `/attendance` → 결석신고서 `/attendance/reports`, 통계 `/attendance/stats`
  - 상담일지 `/counseling`
  - 학급 `/class/roster` → 명단 `/class/roster`, 명렬표 `/class/sheet`, 자리배치 `/class/seating`, 청소배치 `/class/cleaning`, 반성문 `/class/reflection`(이번엔 '준비 중' 화면)
  - 설정 `/settings` (맨 아래)
- 하위 메뉴는 그 부모 주소일 때 펼쳐진다. 옛 주소(`/reports`, `/stats`, `/class`)는 새 주소로 넘겨 준다.
- 숫자 표시: 출결 옆 = 이번 달 미제출 신고서 수, 상담일지 옆 = 미정리 기록 수. 자료가 바뀌면 다시 센다(Dexie liveQuery).
- 이름 가림 버튼은 사이드바에서 빼고(설정 > 화면, Ctrl+Shift+H), 켜져 있으면 화면 위에 '이름 가림 중 · 끄기' 띠를 보인다.
- 맨 아래 작게 'v0.5.0'.

## 4. 학급 화면
- 탭 대신 하위 메뉴 주소로 화면을 나눈다(같은 부품 재사용).
- 명단: 왼쪽 좁은 목록(번호·이름, 전출은 흐리게 맨 아래, 찾기 칸) + 오른쪽 상세(누르면 열림, 기본은 첫 학생). 표 전체 보기는 '명렬표' 화면이 맡는다.

## 5. 단축키 (한 곳에서 관리: `src/lib/ui/shortcuts.ts`)
| 키 | 동작 |
|---|---|
| Ctrl+K | 명령 입력 열기(설계서 2 전에는 홈으로 이동 + 입력 칸 커서) |
| Ctrl+1~6 | 홈·달력·출결·상담일지·학급·설정 |
| Alt+← / Alt+→ | 화면이 내보낸 '앞/뒤' 동작(출결 날짜, 달력·신고서·통계 달) |
| Ctrl+E | 화면의 내보내기 메뉴 열기 |
| Ctrl+P | 인쇄(기본) |
| Ctrl+Shift+H | 이름 가림 켜기/끄기 |
| Esc | 떠 있는 창·메뉴 닫기 |
- 글자 칸 안에서는 Ctrl/Alt 조합만 듣는다. 화면별 동작은 `useShortcut('step', fn)` 같은 훅으로 등록·해제.
- 설정 > 화면에 단축키 표를 보인다.

## 6. 내보내기 통일
- 부품 `<ExportMenu items={[{format:'hwpx'|'xlsx'|'pdf', run}]}/>` — 버튼 하나 '내보내기 ▾', 형식별 항목.
- PDF는 공통 `exportPdf(title)`: 인쇄용 CSS로 그 화면을 PDF로(브리지 있으면 바로 저장, 없으면 인쇄 대화상자).
- 화면별 형식:
| 화면 | 한글 | 엑셀 | PDF |
|---|---|---|---|
| 결석신고서 | 있음(신고서) | 새로(목록) | 새로 |
| 통계 | 있음 | 있음 | 새로 |
| 상담일지 | 있음 | 있음 | 새로 |
| 명렬표 | 있음 | 새로 | 새로 |
| 자리배치 | 있음 | 새로(칸=자리) | 새로 |
| 청소배치 | 있음 | 있음 | 새로 |
| 달력 | — | 새로(그달 일정 목록) | 새로 |

## 7. 그 밖의 정리
- 백업 알림 띠에 '오늘은 그만 보기'(device_local에 날짜 저장).
- 화면 머리(제목·요약·도구)를 공통 부품 `<PageHead>`로(품질-1).

## 8. 시험과 확인
- 단위: 단축키 해석, 메뉴 숫자 세기, 옛 주소 넘기기, userData 경로 선택(옛 폴더 있으면 그대로).
- 화면: 모든 메뉴·하위 메뉴 캡처(기본·어둡게 테마), 이름 가림 띠, 내보내기 메뉴.
- exe: Windows 빌드 후 기존 자료가 든 폴더로 실행해 학생 목록이 보이는지(가상 자료로 재현).

## 9. 하지 않는 것
- 명령 입력·대화 기록(설계서 2), 반성문 내용(새 기능 단계).
