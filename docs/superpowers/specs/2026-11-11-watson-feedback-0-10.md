# 설계서 8: 0.10 사용자 점검 반영

출처: 사용자 11/11 두 번째 점검. 비교로 보내 준 화면은 다른 앱(WeeLog) 노트함이다. 단색 선 아이콘을 쓰고, 폴더 줄에 + ✎ 🗑이 있다.
exe는 바꾸지 않는다.

## 1. 홈

1. **대답 아래 작은 아이콘:** 결과 카드의 '복사'·'노트로' 글자 단추를 없앤다.
   - 대신 카드(말풍선) 바로 아래에 작은 단색 아이콘 두 개(복사, 노트로)를 둔다. Claude 앱처럼.
   - 평소에는 흐리게 보이고, 마우스를 올리면 진하게 바뀐다.
   - 아이콘마다 title과 aria-label을 단다.
   - 복사하면 2초 동안 ✓로 바뀐다.
2. **좁은 대화 칸:** 대화 칸 너비에 맞춰 말풍선이 비율로 줄어든다(container query).
   - 대화 칸이 520px보다 좁으면 글자를 13px로 줄이고, 안쪽 여백도 줄인다.
   - 말풍선 최대 너비는 내 말 75%, 대답 88%로 둔다.
3. **할 일 순서:** 할 일 줄 왼쪽 손잡이(⋮⋮)를 끌어 위아래로 옮긴다. 저장은 기존 order 칸을 쓴다.
4. **전달사항 칸 자리:** 전달사항도 홈 칸 중 하나(`notice`)가 되어, 오른쪽에도 왼쪽 탭에도 둘 수 있다.
   - 기본 자리는 왼쪽 탭이다.
   - 전달사항이 오른쪽에 있으면 왼쪽 탭은 대화 하나만 남는다.
5. **전달사항 머리 도구:** 글자 단추를 단색 아이콘으로 바꾼다. 색은 넣지 않고, 왼쪽 탭처럼 흐린 아이콘이다.
   - 가져오기: 붙여넣어 AI로 나누기
   - 노트로 보내기
   - 내보내기: 한글·엑셀·PDF·바로 인쇄
   - 전체 지우기: 한 번 더 묻고, 되돌리기를 둔다
6. **오른쪽 열 위치:** 오른쪽 열은 맨 위(날짜 줄)부터 시작한다.
   - 왼쪽 열: 날짜·요약 줄 → 시작하기 안내 → 탭 → 대화.
   - 그래서 시작하기 안내 상자는 왼쪽 열 너비로만 차지한다.
7. **요약 줄:** 날짜·수업일 아래 요약 줄의 순서는 내 수업 · 방학 D-day · 출결 · 미제출 신고서다.
   - 방학 D-day: 학사일정에서 오늘 뒤 가장 가까운, 제목에 '방학'이 든 일정. 없으면 뺀다.
   - '급식·시간표' 글자는 없애고 ▾ 아이콘만 둔다.
   - ▾를 누르면 출결 상황, 시간표 상세, 급식이 펼쳐진다.

## 2. 달력

- 주는 일요일부터 시작한다(일 월 화 수 목 금 토).
- 출결의 작은 달력은 월~금 수업일만 보이므로 그대로 둔다.

## 3. 노트함

1. **아이콘:** 폴더와 노트에 메뉴와 같은 단색 선 아이콘(folder, file)을 쓴다. 📁 이모지는 쓰지 않는다.
2. **끌어 옮기기:** HTML 끌어놓기를 쓰지 않고, 포인터(마우스)로 끄는 방식으로 바꾼다. 끌기를 시작할 때 목록을 다시 그려서 끌기가 끊기던 것으로 보인다.
   - 노트를 폴더 위에 놓으면 그 폴더로 들어간다.
   - 노트를 다른 노트 사이에 놓으면 그 자리로 순서가 바뀐다. 다른 폴더의 노트 사이에 놓으면 그 폴더로 옮겨진다.
   - 끄는 동안 놓일 자리에 선을 보여 주고, 폴더 위면 폴더를 강조한다.
   - 순서는 노트의 `order`(선택 필드)에 둔다. 고정한 노트가 먼저 오고, 그다음 order, 그다음 최근에 고친 순이다.
   - 5px 넘게 움직였을 때만 끌기로 본다. 그보다 적게 움직이면 클릭(열기)이다.
3. **폴더 줄 도구:**
   - +: 그 폴더에 새 노트(바로 연다)
   - ✎: 이름 바꾸기
   - 🗑(휴지통 아이콘): 폴더 지우기(묻기)
   - 하위 폴더는 폴더를 고른 뒤 '+ 폴더'로 만든다.

## 4. 내보내기

- 모든 '내보내기' 메뉴에 '바로 인쇄'를 더한다(window.print, 지금 화면).
