# Watson 0.17 — 안전 보강 (exe 그대로)

근거: 대변혁 사전 점검 문서(2026-11-13)의 코드 리뷰·보안 점검·실제 실행 결과. 사용자 결정: 진행, HTML판 폐지, 다른 선생님께 배포(소수), 개인 Gmail, 안드·아이폰, 휴대폰은 출결·상담 기록.

목표: 자료를 잃거나 새게 하는 구멍을 exe 변경 없이(셸 1) 막는다. 화면 정리(디자인 체계)는 0.18.

## 요구 사항

### A. 백업·복원
1. **백업 형식 번호 분리**: Dexie 판 번호와 백업 형식 번호를 나눈다(`BACKUP_FORMAT_VERSION = 2`). 표 목록이 바뀌면 형식 번호를 올리게 하는 시험을 둔다.
2. **옛 백업 복원 시 없는 표는 그대로 둔다**: 백업 파일에 없는 표(예: 노트가 생기기 전 백업)는 지우지 않는다. 있는 표만 백업 내용으로 바꾼다.
3. **첨부 한도 낮춤**: 전체 첨부 500MB → 150MB(백업 한 덩어리 글자 수 한도 아래). 한 파일 50MB는 그대로. 크기 합은 표를 다 읽지 않고 계산(size 필드만).
4. **자동 백업 주기 확인**: 앱을 켤 때뿐 아니라 1시간마다, 창이 다시 보일 때도 기한을 확인한다. 동시에 두 번 돌지 않는다.
5. **복원 후 화면 새로 불러오기**: '복원했습니다. 화면을 새로 불러옵니다.' 뒤 다시 불러온다.
6. **암호구 바꿀 때 경고**: 이미 암호구가 있으면 '이전 백업 파일은 예전 암호구로만 열립니다' 안내, 단추는 '암호구 바꾸기'.
7. **보관 정리**: 같은 날 여러 번 백업해도 예전 날짜 백업이 밀려나지 않게, 날짜별 마지막 1개를 보관 개수만큼 남기고 오늘 것은 모두 남긴다.

### B. 입력·자료 잃음
8. **창 닫을 때 저장**: 노트 편집기와 누가기록 입력 칸은 `pagehide`·`beforeunload`·화면 숨김 때 미뤄 둔 저장을 바로 한다.
9. **첨부 파일 정리 시점**: 블록에서 빠진 첨부를 저장할 때 지우지 않는다. 앱을 켤 때 '어느 노트에서도 쓰지 않고 하루 넘은' 첨부만 비운다(되돌리기·다른 노트에 붙여넣기 보호).
10. **누가기록 지우기 확인**: '지우기'를 누르면 같은 자리에서 '지울까요? [지우기] [취소]'.
11. **전달사항 노트 중복 방지**: 같은 날 노트 만들기를 한 묶음 저장으로, 단추는 처리 중 잠금.

### C. 개인정보
12. **AI 가리기 확대**: 주민등록번호 → `[주민N]`, 이메일 → `[메일N]`. 가릴 이름에 보호자 이름과 지운 학생 이름을 넣는다.
13. **구글 캘린더로 보내는 글**: 전체 학생·보호자 이름을 ○○로, 전화·주민번호·이메일도 가린다.
14. **HTML판 종료**: HTML판(단일 파일)에서는 업데이트 확인을 멈추고 '종료 안내' 띠를 늘 보인다: 설치형으로 옮기는 법(백업 파일 내려받기 → 설치형에서 복원). 서명 없는 HTML 받기 경로는 코드에서 지운다. 0.17이 마지막 HTML 빌드.

### D. 바로 고칠 사용성
15. **노트 제목 Enter·↓**: 본문 첫 줄로 간다(한글 조합 중 Enter는 무시).
16. **/결석·/지각·/조퇴·/결과**: `/출결`의 다른 이름. 쓴 이름이 종류가 된다.
17. **좁은 화면 표**: 통계·명단 전체 표는 가로 스크롤 + 번호·이름 열 고정. 설정 화면이 800px에서 넘치지 않게.
18. **W 단추가 내용을 가리지 않게**: 본문 아래 여백.
19. **낱말 통일**: 화면 문구의 '삭제'를 '지우기'로.
20. **/내보내기 … 엑셀**: 실제로 내보낸 뒤에 결과를 말한다(실패도).

## 시험
각 항목은 실패하는 시험을 먼저 쓴다. 끝에 전체 시험 통과, 실제 브라우저 캡처로 15·17·18 확인.

자료·키 암호화, 업데이트 되돌리기·전체 서명, Electron fuses·권한, Antigravity stdin, 구글 계정 연결(비민감 권한)·드라이브 동기화, 큰 파일 나누기.
