담임업무 개인정보처리방침

시행일: 2026년 11월 9일

1. 저장 위치

학생 명단, 출결, 상담 기록 등 프로그램에 입력한 모든 자료는 사용자 본인의 컴퓨터에만 저장됩니다. 개발자나 다른 서버로 보내지 않습니다. 백업 파일은 사용자가 정한 비밀번호로 암호화되어 사용자가 고른 폴더에 저장됩니다.

2. 구글 사용자 데이터

  • 사용 범위: 사용자가 "구글로 로그인"을 누른 경우에만 다음 권한을 요청합니다. 프로그램이 만든 캘린더("학사일정(담임업무)")의 생성·관리, 사용자 캘린더 목록과 일정 읽기.
  • 사용 목적: 학사일정과 결석신고서 정리 알림을 위 캘린더에 넣고, 사용자의 기본 캘린더 일정을 프로그램 달력에 보여 주기 위해서만 사용합니다.
  • 보관: 가져온 일정은 사용자 컴퓨터에만 저장되며, 로그인 정보는 운영체제 암호화 저장소에 보관됩니다. 개발자를 포함한 제3자에게 전송·공유·판매하지 않습니다.
  • 구글로 보내는 내용: 학사일정 제목·날짜와 "결석신고서 정리(미제출 N건, 번호)" 알림뿐이며 학생 이름은 보내지 않습니다.
  • 삭제: 프로그램의 "로그아웃"을 누르면 로그인 정보가 지워지고 권한이 취소됩니다. 구글 계정 권한 페이지에서도 언제든 취소할 수 있습니다.

담임업무의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. AI 기능

사용자가 AI 정리 기능을 켜고 버튼을 누른 경우에만, 학생 이름·전화번호·학번을 가린 메모를 사용자 본인의 Claude 계정(또는 사용자가 넣은 키)으로 Anthropic에 보내 정리합니다.
